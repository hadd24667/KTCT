# Website ôn thi trắc nghiệm Kinh tế chính trị Mác - Lênin

## Cách chạy

Mở trực tiếp file `index.html` bằng trình duyệt Chrome/Edge/Firefox. Website chạy offline, không cần cài Node.js hay server.

## Nội dung đã nạp

- Bộ PDF 200 câu: 201 mục câu hỏi. Lưu ý PDF gốc có 2 câu cùng đánh số 43, website giữ cả hai để không mất dữ liệu.
- Bộ DOCX theo chương: 810 câu hỏi có đáp án, chia theo 5 chương.

## Chức năng chính

- Chọn 1 trong 2 loại đề.
- Lọc theo chương đối với bộ DOCX.
- Chọn số câu: 10, 20, 50, 100 hoặc tất cả.
- Xáo trộn câu hỏi.
- Chế độ luyện tập: chọn xong hiện đúng/sai ngay.
- Chế độ kiểm tra: nộp bài rồi mới chấm.
- Hỗ trợ câu có nhiều đáp án đúng.
- Thống kê số câu đúng, sai, chưa làm, phần trăm điểm.
- Xem lại câu sai và tải kết quả dạng JSON.

## Ghi chú kiểm tra dữ liệu

Số vấn đề phát hiện khi trích xuất: 0.
- Không phát hiện lỗi nghiêm trọng trong câu hỏi/đáp án.
